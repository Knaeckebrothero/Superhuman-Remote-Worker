Overview

Self-hosted AI agents with persistent memory and source citations.

Superhuman Remote Worker is an orchestration platform for AI agents. It schedules long-running jobs across a fleet of isolated workspaces, persists agent memory in pgvector, and maintains a shared knowledge graph in Neo4j. Run it as a managed subscription, or deploy the Helm chart in your own Kubernetes cluster.

Why self-host

What you give up on closed-SaaS agent platforms.

  • Your prompts, embeddings, and graph live in the vendor's tenant. Exports are limited or unavailable.
  • The vendor controls memory retention. You don't decide what's kept or for how long.
  • No audit trail you can query or export. Compliance and forensics depend on whatever the vendor surfaces.
  • One generic assistant role. No way to define specialized agents for different kinds of work.

How it works

Three components, one workflow.

Tier 1

Orchestrator

FastAPI service. Schedules jobs, persists state to PostgreSQL, mediates between the cockpit and the agent fleet.

Tier 2

Agents

LangGraph workers running in isolated, SSH-accessible workspaces. Each run alternates planning and execution; memory persists between them.

Tier 3

Cockpit

Angular dashboard. Inspect runs, approve checkpoints, redirect agents during a job.

What you get

Built-in capabilities.

Multi-agent orchestration

Parallel jobs across a fleet of agents, scheduled and supervised.

Persistent memory

Vector and relational state per agent. Survives restarts and redeploys.

Isolated workspaces

Each run gets its own filesystem and SSH endpoint.

Citation engine

Every factual claim links to the source the agent actually read.

Knowledge graph

Neo4j-backed. Agents query and extend it as they work.

MCP integration

Tools exposed over Model Context Protocol — bring your own server.

OIDC via Keycloak

SSO with role-based access. Roles map to agent capabilities.

YAML specialists

Specialized agents defined in YAML. Ships with scholar, developer, critic, and curator presets.

Audit log

Append-only audit log in MongoDB. Queryable for compliance and forensics.

Built on

FastAPI · LangGraph · PostgreSQL/pgvector · MongoDB · Neo4j · Keycloak · Redis · Angular

Two ways to run it

Same codebase, different operating model.

Hosted

Managed subscription. We run the orchestrator, the database cluster, the agent fleet, and the upgrades. You sign in and use it. Best when you don't want to operate Kubernetes yourself.
