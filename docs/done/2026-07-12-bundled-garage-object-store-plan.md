**Goal:** Add an opt-in, single-node Garage S3 object store to the Helm chart that, when enabled, auto-backs workspace snapshots and the virtual workspace tier with zero external S3 dependency.

**Architecture:** Mirror the existing `databases/postgres.yaml` bundled-stateful pattern (PVC + StatefulSet + Service) plus the `keycloak/bootstrap-job.yaml` post-install-hook pattern. A Helm-hook Job drives Garage's **admin HTTP API** (the `dxflrs/garage` image is shell-less, so the `garage` CLI cannot be exec'd) to assign a single-node layout, create the two buckets, and import two pre-set scoped access keys. Credentials live in the app Secret — auto-generated by the chart in chart-managed mode (reusing the `APP_ENCRYPTION_KEY` lookup-or-generate idiom), or pulled from Vault via the existing `dataFrom: extract` ExternalSecret. `_helpers.tpl` auto-wires the in-cluster endpoints into `configmap.yaml` only when Garage is enabled AND the matching external endpoint is empty (external always wins).

**Tech Stack:** Helm 3 (Go templating + sprig), Garage `v1.0.1`, `curlimages/curl:8.11.0` for the bootstrap Job, kubeconform for CI schema validation.

## Global Constraints

- **Chart-only.** No orchestrator/agent Python changes. This PR adds no new env-var contract — it reuses the Secret keys the consumers already read.
- **Reused consumer Secret keys (verified in `orchestrator/deployment.yaml`):** `SNAPSHOT_S3_ACCESS_KEY_ID`, `SNAPSHOT_S3_SECRET_ACCESS_KEY` (snapshots, orchestrator-side); `VIRTUAL_WORKSPACE_S3_ACCESS_KEY_ID`, `VIRTUAL_WORKSPACE_S3_SECRET_ACCESS_KEY` (virtual tier, agent-side).
- **New Secret keys:** `GARAGE_RPC_SECRET` (must be a 32-byte / 64-char **hex** string — generate with `sha256sum (randAlphaNum 32)`), `GARAGE_ADMIN_TOKEN` (any bearer string).
- **Garage ports:** `3900` S3 API, `3901` RPC, `3903` admin API.
- **Buckets:** snapshots bucket = `.Values.s3.bucket` (default `srw-snapshots`, single source of truth); workspace bucket = `.Values.garage.buckets.workspaces` (default `srw-workspaces`).
- **External always wins:** auto-wiring only fills an endpoint when Garage is enabled AND that endpoint value is empty.
- **Not for production.** Single replica, PVC-bound, no replication/erasure. Say so loudly in `values.yaml` + `NOTES.txt`.
- **Follow existing patterns/helpers:** `srw.fullname`, `srw.serviceName (dict "context" . "component" "garage")`, `srw.componentLabels`, `srw.componentSelectorLabels`, `srw.secretName`, `srw.configMapName`.
- **Readiness must be TCP, not Garage `/health`.** `/health` returns 503 until a layout is applied — an httpGet readiness probe would deadlock the bootstrap (Service has no endpoints → Job can't reach admin API to apply the layout). Use `tcpSocket: 3900`.
- **Git:** work on `develop`. Commit after every task. **Do NOT push** (ask first).
- **Spec:** `docs/done/2026-07-12-bundled-garage-object-store-design.md`.

```yaml
{{- if .Values.garage.enabled }}
# Garage bootstrap — post-install/upgrade hook. The dxflrs/garage image is
# shell-less, so we drive the admin HTTP API from a shell+curl image instead of
# exec'ing the garage CLI. Idempotent: every step is check-or-ignore-conflict.
apiVersion: batch/v1
kind: Job
metadata:
  name: {{ include "srw.fullname" . }}-garage-bootstrap
  labels:
    {{- include "srw.componentLabels" (dict "context" . "component" "garage-bootstrap") | nindent 4 }}
  annotations:
    "helm.sh/hook": post-install,post-upgrade
    "helm.sh/hook-delete-policy": before-hook-creation,hook-succeeded
spec:
  backoffLimit: 10
  template:
    metadata:
      labels:
        {{- include "srw.componentSelectorLabels" (dict "context" . "component" "garage-bootstrap") | nindent 8 }}
    spec:
      restartPolicy: OnFailure
      {{- with .Values.global.imagePullSecrets }}
      imagePullSecrets:
        {{- toYaml . | nindent 8 }}
      {{- end }}
      # When ESO owns the app Secret it may not be synced yet at hook time;
      # wait for the keys we need before the main container starts.
      initContainers:
        - name: wait-for-creds
          image: busybox:1.36
          command:
            - sh
            - -c
            - |
              until test -s /creds/GARAGE_ADMIN_TOKEN \
                && test -s /creds/SNAPSHOT_S3_ACCESS_KEY_ID \
                && test -s /creds/VIRTUAL_WORKSPACE_S3_ACCESS_KEY_ID; do
                echo "waiting for garage creds in the app Secret"; sleep 2
              done
          volumeMounts:
            - name: creds
              mountPath: /creds
              readOnly: true
      containers:
        - name: bootstrap
          image: {{ .Values.garage.bootstrap.image }}
          env:
            - name: GARAGE_SVC
              value: {{ include "srw.fullname" . }}-garage
            - name: GARAGE_CAPACITY_BYTES
              value: {{ .Values.garage.capacityBytes | quote }}
            - name: SNAPSHOT_BUCKET
              value: {{ .Values.s3.bucket | quote }}
            - name: WORKSPACE_BUCKET
              value: {{ .Values.garage.buckets.workspaces | quote }}
            - name: GARAGE_ADMIN_TOKEN
              valueFrom:
                secretKeyRef:
                  name: {{ include "srw.secretName" . }}
                  key: GARAGE_ADMIN_TOKEN
            - name: SNAPSHOT_S3_ACCESS_KEY_ID
              valueFrom:
                secretKeyRef:
                  name: {{ include "srw.secretName" . }}
                  key: SNAPSHOT_S3_ACCESS_KEY_ID
            - name: SNAPSHOT_S3_SECRET_ACCESS_KEY
              valueFrom:
                secretKeyRef:
                  name: {{ include "srw.secretName" . }}
                  key: SNAPSHOT_S3_SECRET_ACCESS_KEY
            - name: VIRTUAL_WORKSPACE_S3_ACCESS_KEY_ID
              valueFrom:
                secretKeyRef:
                  name: {{ include "srw.secretName" . }}
                  key: VIRTUAL_WORKSPACE_S3_ACCESS_KEY_ID
            - name: VIRTUAL_WORKSPACE_S3_SECRET_ACCESS_KEY
              valueFrom:
                secretKeyRef:
                  name: {{ include "srw.secretName" . }}
                  key: VIRTUAL_WORKSPACE_S3_SECRET_ACCESS_KEY
          command:
            - sh
            - -c
            - |
              set -eu
              ADMIN="http://${GARAGE_SVC}:3903"
              AUTH="Authorization: Bearer ${GARAGE_ADMIN_TOKEN}"

              # 1. Wait for the admin API.
              i=0
              until curl -sf -H "$AUTH" "$ADMIN/v1/status" >/tmp/status 2>/dev/null; do
                i=$((i+1)); [ "$i" -gt 90 ] && { echo "garage admin API not ready"; exit 1; }
                echo "waiting for garage admin API ($i)"; sleep 2
              done

              NODE=$(sed -n 's/.*"node"[[:space:]]*:[[:space:]]*"\([0-9a-f]\{16,\}\)".*/\1/p' /tmp/status | head -1)
              [ -n "$NODE" ] || { echo "could not parse node id"; cat /tmp/status; exit 1; }
              echo "node=$NODE"

              # 2. Assign single-node layout if this node has no role yet.
              curl -sf -H "$AUTH" "$ADMIN/v1/layout" >/tmp/layout
              VER=$(sed -n 's/.*"version"[[:space:]]*:[[:space:]]*\([0-9]\{1,\}\).*/\1/p' /tmp/layout | head -1)
              VER=${VER:-0}
              if ! grep -q "\"$NODE\"" /tmp/layout; then
                curl -sf -X POST -H "$AUTH" -H 'Content-Type: application/json' \
                  -d "[{\"id\":\"$NODE\",\"zone\":\"dc1\",\"capacity\":${GARAGE_CAPACITY_BYTES},\"tags\":[]}]" \
                  "$ADMIN/v1/layout" >/dev/null
                NEXT=$((VER+1))
                curl -sf -X POST -H "$AUTH" -H 'Content-Type: application/json' \
                  -d "{\"version\":${NEXT}}" "$ADMIN/v1/layout/apply" >/dev/null
                echo "layout applied v${NEXT}"
              else
                echo "layout already assigned"
              fi

              # 3. Bucket + scoped-key setup.
              setup() {
                bucket="$1"; keyid="$2"; keysec="$3"; keyname="$4"
                curl -s -X POST -H "$AUTH" -H 'Content-Type: application/json' \
                  -d "{\"globalAlias\":\"$bucket\"}" "$ADMIN/v1/bucket" >/dev/null || true
                curl -sf -H "$AUTH" "$ADMIN/v1/bucket?globalAlias=$bucket" >/tmp/b
                bid=$(sed -n 's/.*"id"[[:space:]]*:[[:space:]]*"\([0-9a-f]\{16,\}\)".*/\1/p' /tmp/b | head -1)
                [ -n "$bid" ] || { echo "no bucket id for $bucket"; cat /tmp/b; exit 1; }
                curl -s -X POST -H "$AUTH" -H 'Content-Type: application/json' \
                  -d "{\"name\":\"$keyname\",\"accessKeyId\":\"$keyid\",\"secretAccessKey\":\"$keysec\"}" \
                  "$ADMIN/v1/key/import" >/dev/null || true
                curl -sf -X POST -H "$AUTH" -H 'Content-Type: application/json' \
                  -d "{\"bucketId\":\"$bid\",\"accessKeyId\":\"$keyid\",\"permissions\":{\"read\":true,\"write\":true,\"owner\":false}}" \
                  "$ADMIN/v1/bucket/allow" >/dev/null
                echo "configured bucket=$bucket key=$keyname"
              }
              setup "$SNAPSHOT_BUCKET" "$SNAPSHOT_S3_ACCESS_KEY_ID" "$SNAPSHOT_S3_SECRET_ACCESS_KEY" "srw-snapshots"
              setup "$WORKSPACE_BUCKET" "$VIRTUAL_WORKSPACE_S3_ACCESS_KEY_ID" "$VIRTUAL_WORKSPACE_S3_SECRET_ACCESS_KEY" "srw-workspaces"
              echo "garage bootstrap complete"
          resources:
            {{- toYaml .Values.garage.bootstrap.resources | nindent 12 }}
      volumes:
        - name: creds
          secret:
            secretName: {{ include "srw.secretName" . }}
{{- end }}
```

### Task 6: Auto-generate bundled-store credentials in `secret.yaml`

**Files:**
- Modify: `helm/templates/secret.yaml`

**Interfaces:**
- Consumes: `.Values.garage.enabled`, `.Values.secrets.values`, `.Values.secrets.create`.
- Produces: Secret keys `GARAGE_RPC_SECRET`, `GARAGE_ADMIN_TOKEN`, `SNAPSHOT_S3_ACCESS_KEY_ID`, `SNAPSHOT_S3_SECRET_ACCESS_KEY`, `VIRTUAL_WORKSPACE_S3_ACCESS_KEY_ID`, `VIRTUAL_WORKSPACE_S3_SECRET_ACCESS_KEY` — read by Tasks 4 & 5 and by the orchestrator/agent at runtime.

> **Design note:** reuse the existing `APP_ENCRYPTION_KEY` idiom already in this file: operator-provided `secrets.values.<KEY>` wins; else the value already in the live Secret is preserved via `lookup`; else generate. This makes the bundled store zero-config in chart-managed mode while staying upgrade-safe. In ESO mode (`secrets.create=false`) this file does not render — the operator supplies the six keys in the Vault path, and the main ExternalSecret's `dataFrom: extract` pulls them (no template change needed).

- [ ] **Step 1: Write the failing test**

```bash

  | grep -E 'GARAGE_RPC_SECRET|GARAGE_ADMIN_TOKEN|SNAPSHOT_S3_ACCESS_KEY_ID|VIRTUAL_WORKSPACE_S3_ACCESS_KEY_ID'
```
Expected now: no such keys in the Secret (`eval-values.yaml` sets `secrets.create: true`).

- [ ] **Step 2: Add a generation helper block + emit the keys**

In `helm/templates/secret.yaml`, after the existing `$appKey` computation block (after line ~31, before `apiVersion: v1`), add:

```gotemplate
{{- /*
Bundled Garage object store credentials. Same lookup-or-generate semantics as
APP_ENCRYPTION_KEY: operator value wins, else preserve the live Secret's value,
else generate. Only emitted when garage.enabled. GARAGE_RPC_SECRET must be a
32-byte hex string — sha256sum of a random string gives 64 hex chars.
*/ -}}
{{- $garageKeys := dict }}
{{- if .Values.garage.enabled }}
{{- $defaults := dict
      "GARAGE_RPC_SECRET" (sha256sum (randAlphaNum 32))
      "GARAGE_ADMIN_TOKEN" (randAlphaNum 32)
      "SNAPSHOT_S3_ACCESS_KEY_ID" (randAlphaNum 20)
      "SNAPSHOT_S3_SECRET_ACCESS_KEY" (randAlphaNum 40)
      "VIRTUAL_WORKSPACE_S3_ACCESS_KEY_ID" (randAlphaNum 20)
      "VIRTUAL_WORKSPACE_S3_SECRET_ACCESS_KEY" (randAlphaNum 40) }}
{{- range $k, $gen := $defaults }}
{{- $v := index $.Values.secrets.values $k | default "" }}
{{- if not $v }}
{{- if and $existing $existing.data (index $existing.data $k) }}
{{- $v = index $existing.data $k | b64dec }}
{{- end }}
{{- end }}
{{- if not $v }}{{- $v = $gen }}{{- end }}
{{- $_ := set $garageKeys $k $v }}
{{- end }}
{{- end }}
```

Then, inside `stringData:`, after the `APP_ENCRYPTION_KEY` line (line ~40) and before the `range` over `secrets.values`, add:

```gotemplate
  {{- range $k, $v := $garageKeys }}
  {{ $k }}: {{ $v | quote }}
  {{- end }}
```

Finally, update the existing `range` over `.Values.secrets.values` so operator-supplied garage keys aren't emitted twice — change the `if ne $key "APP_ENCRYPTION_KEY"` guard (line ~42) to also skip keys already in `$garageKeys`:

```gotemplate
  {{- range $key, $value := .Values.secrets.values }}
  {{- if and (ne $key "APP_ENCRYPTION_KEY") (not (hasKey $garageKeys $key)) }}
  {{ $key }}: {{ $value | quote }}
  {{- end }}
  {{- end }}
```
