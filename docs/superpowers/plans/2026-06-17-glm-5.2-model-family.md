# GLM-5.2 Model Family Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `glm` model family (Zhipu GLM-5.2) with specialized settings and prompts for both the worker and persistent-chat paths.

**Architecture:** GLM-5.2 is a text-only, ~1M-context hybrid-reasoning model served via OpenRouter (OpenAI-compatible wire) — a near-exact analogue of the existing `deepseek` family. We mirror that pattern: a `glm` block in `config/model_config_matrix.yaml`, three forked prompts (worker `systemprompt`, persistent-chat `systemprompt_interactive`, `persona`), an empty `glm.yaml` guardrails file, and a `glm` branch in all four family-detection sites that must stay in sync.

**Tech Stack:** Python 3.12 (pytest), YAML config matrix, Angular/TypeScript cockpit (vitest).

**Spec:** [`docs/superpowers/specs/2026-06-17-glm-5.2-model-family-design.md`](../specs/2026-06-17-glm-5.2-model-family-design.md)

## Global Constraints

- **Branch/commit:** Work directly on `develop`; do NOT create feature branches. Commit per task. Do NOT push (the user pushes).
- **Commit trailer:** End every commit message with `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`.
- **Test gate:** CI (Python 3.12) is the authority; local pytest is env-noisy (Py3.14, missing optional deps). Run the **specific** new tests by node id, not the whole suite.
- **Four detection sites must agree:** `family_of()` (Python), `detect_family()` (orchestrator), `detectModelFamily()` (TS), and the `FAMILIES` array. The matrix family key MUST equal `family_of()` output: exactly `glm`.
- **Reasoning effort is NOT a matrix setting** — it rides on the per-model catalog row (`reasoning_level`). Do not add a reasoning key to the matrix.
- **GLM-5.2 is text-only** — `multimodal: false`, and do NOT add `image_tokens` / `pdf_render_dpi`.
- **Settings keys** that reach `LLMConfig`: `temperature, top_p, top_k, multimodal, parallel_tool_calls, model_max_context_tokens`. Unknown keys are silently ignored.
- **Derived limits:** `context_threshold_tokens = base × 0.80`; `message_count_min_tokens = base × 0.40`. For GLM base `1000000` → `800000` / `400000`.

class TestGlmFamily:
