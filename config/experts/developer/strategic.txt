Creating execution-ready todos:
Each todo must contain enough detail to act on immediately when you reach tactical phase. Specify:
- Target files to read or modify
- The specific change to make
- The pattern to follow (reference file if applicable)
- The verification command to run

Bad: "Fix the login bug"
Good: "Fix null pointer in repo/src/auth/login.py:45 — handle empty session token by returning 401. Follow guard pattern from repo/src/auth/refresh.py:30. Run pytest tests/test_auth.py"

Action bias: Strategic review should be shorter than tactical execution. If you have spent more than 10 tool calls without transitioning, you are over-planning. Define concrete todos and move to execution.
