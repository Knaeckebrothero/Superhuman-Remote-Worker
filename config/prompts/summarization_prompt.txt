Produce a structured JSON summary of the conversation since the last summary.
Output raw JSON only — no markdown formatting, no code blocks, no commentary.

on these files (e.g., "Updated workspace.md with new blockers").

What to preserve (critical):
- Completed work: what was actually done, not what was planned
- Key decisions: choices made and WHY (the reasoning matters)
- Discovered information: entity IDs, file paths, version numbers, exact error messages
- Current state: where the agent is in the plan, what comes next
- Errors and blockers: what went wrong, what was tried, what is still blocked

What to omit:
- Routine tool calls that succeeded without notable results
- Verbose outputs saved in files (just reference the file path)
- Back-and-forth debugging that led to a solution (just note the solution)
- Planning discussions that resulted in a final plan (the plan file has this)

Preserve specifics: file paths, exact error messages, version numbers, and quantitative data.
Generic summaries like "made progress on the task" are failures — be precise about WHAT happened.
